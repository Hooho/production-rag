# 北海慢游指南：评测题与评分依据

本文件是评测人员用的答案与实验说明，不导入知识库。检索语料包括 corpus/北海慢游指南.md 与 corpus/北海出游条件补记.md；四道新版比较题使用补记，其余题继续使用原指南。所有答案以该虚构世界为准，不引入现实北海的信息补全缺失条件。B001 等编号是定位证据的小节标识，不应作为问题的一部分或额外提示发送给 Agent。

## 一、要区分的三种能力

多跳检查能否在没有下一跳名称的起点问题下，沿唯一的资料内关联逐步发现下一份资料。比较检查子问题召回的必要证据，是否在使用完整问题重排时因低分被过滤。汇总检查面对宽泛需求，能否形成暂时判断、主动查证，在发现限制后改变查询角度，形成满足条件的综合回答。

这三种机制都不能仅靠答案看起来合理来确认。多跳要看逐轮查询与证据来源；比较要看召回候选、重排分数和阈值过滤；汇总要看证据是否触发查询调整。任何题目都不得以工具次数越多越好计分。一次搜索返回了全部证据，需要如实记为捷径，而不是伪装成多轮推理成功。

四道新版比较题已使用本机缓存的 BGE 向量与重排权重做离线实测：子查询召回和完整问题过滤结果见后文。实现为 PyTorch CPU，实际部署使用 fastembed/ONNX，且线上配置未知，因此本地结果不等于线上已复现。多跳直接检索捷径、汇总的 Agent 探索过程、BM25 与上下文扩展仍待实测；句面差异也不代表已经测得语义相似度低。

## 二、运行准备与隔离

先上传指南 Markdown 并完成导入；一键脚本会补充上传、导入《北海出游条件补记》。评测时勾选这两份语料。答案文件、结构检查记录与本文件都不得上传。不要把本套题与其他语料混用后声称链条唯一；其他语料可能补出捷径。

建议首轮将分片大小设为 400 字符、重叠 40 字符。当前切分器按 Markdown 标题建立章节，正文在章节内部按段落与句子处理；短章节不跨标题合并。设置是全局的，会影响随后导入的其他文档；这只是建议，本次未修改运行设置。不要通过编辑一份文档的说明文字假装改变了真实分片参数。

先查看实际分片，记录每条证据对应的文档版本与分片位置。较小参数可能把同一小节分成两片，此时以实际证据所在片为准，不把小节编号当作真实分片 ID。父子分块、邻片扩展、上下文增强、查询改写可能改变实际可见内容，应与参数一起记录。小节相隔很远只能降低邻片捷径，不能禁止全局检索直接命中末端。

多跳题先用原问题执行一轮与正式评测相同规模的检索，观察末端证据是否直接进入候选、通过重排或被邻片展开。如果直接拿到答案，标记为当前配置下“不具备链式辨识力”，不把它算成多跳成功。不得为了保住题目强行要求模型照抄固定查询顺序。

比较题先确保每个子查询能在过滤前的候选中召回必要证据，再保存该证据使用原始完整问题重排的分数。如果子查询根本没召回，应归为召回问题；若完整问题重排后仍保留，应记录“未触发目标故障”。只有原始证据存在而被重排阈值剔除，才证明出现本题要测的现象。

汇总题允许追问用户，也允许在无法追问时声明假设。若用户回答补充偏好，只使用实际收到的回答；不能自行创造偏好。保存外显的查询、工具结果、简短决策说明与最终答案，不要求输出模型的私有思维链。

## 三、多跳题：六条四资料链

共同评分为 10 分：三个中间关联各 2 分，最终所问事实 3 分，准确说明领取或参与条件的边界 1 分。答案正确但没有检索轨迹，只能报告答案正确率，不能给出“已验证逐跳检索”的结论。最短的有效查询可能组合多个已知标识，允许；下一标识尚未出现在可见证据中却被直接查询，应检查是否有提示泄漏。

### M01｜散场接人

问题：参加完周六的「月光拾音」，我和家人应该到哪里等接送，最晚什么时候完成上车，需要带什么？

证据路径：B001 → B025 → B049 → B073。

关联顺序：月光拾音的现场服务机构是砂漏事务所；该机构本期散场交接属于铜铃四册；这一批次由芦码接运承接；最后查接运方的游客须知。

标准答案：在白榕巷北口的黄檐棚等候，二十点十分核对名单，二十点二十五分结束当次上车，须带当晚编号布签。电子报名截图不能替代，不接受现场补位，迟到自行安排交通。

必要原文：B001“现场服务由「砂漏事务所」负责”；B025“归入「铜铃四册」服务批次”；B049“调度页把服务交给「芦码接运」”；B073“白榕巷北口的黄檐棚”“二十点二十五分结束当次上车”“当晚编号布签”。

末端不含活动名或起点机构名。最终地点只在末端出现；节目纸、布袋和装卸棚是需要区分的非凭证或非乘客区域。

关联顺序：纸舟工房 → 薄荷折页规格 → 杉格寄存 → 接收端柜台规则。

标准答案：去青砖书屋后院二号格，周日十五点到十八点受理，凭课程当天压纹纸票原件领取。每张有效票限一个，手机订单、付款记录和作品照片不能代替；前院书屋继续营业不代表后院开放。

必要原文：B010“材料由「纸舟工房」统一提供”；B031“统一采用「薄荷折页」规格”；B051“接收端为「杉格寄存」”；B086“青砖书屋后院二号格”“十五点到十八点”“课程当天的压纹纸票”。

本题不把作品晾干与备用封套领取混为一件事。原问题没有给出工房、规格或寄存端名称。

不得用早先的蓝色纸筒照片、颜料贴纸或签到姓名贴回答凭证问题。

### M04｜盐田合照

### M06｜纪念品核销

问题：「石盘公约」里那项特别的纪念品领取服务，最终在哪个窗口办理，带什么、报什么短语，周日几点停止新申请？

## 四、比较题：六组局部证据与完整问题重排

以下子查询是评测人员的召回诊断建议，不预先发送给 Agent，也不要求 Agent 使用相同措辞。C01—C04 已按本地默认模型和默认阈值筛选，资料拆分为不同主题的运营记录，每题四个计分项。C05—C06 为未重新筛选的备用题，不在一键导入的十二题内。线上仍需核对模型、阈值与过滤前后的记录。

共同答案评分为 10 分：两侧必要事实各 3 分，按共同标准比较 3 分，不捏造缺失条件 1 分。另行报告两侧子查询召回率、原问题重排后的证据保留率，以及单侧证据丢失率。答案分与过滤诊断不能混为一个指标。

### C03｜预约、天气与桌位

问题：雨天不想来回折腾，砂谱听音和珊窗拼片哪种更有把握？请分别核实听音项目临时取消时钱怎么办、拼片项目如果客满是否还能确保参加，再判断预约能解决什么、解决不了什么。

证据来自《北海出游条件补记》，每条计分项单独绑定目标分片：

- B124：听音预约不能消除横向风雨风险。诊断子查询：砂谱听音 雨天 停场 预约回执。
- B135：主办方停场与自行缺席的退款区别。诊断子查询：活动主办方取消 退款 自行缺席 预约款。

- B157：材料券不保座及满座退款条件。诊断子查询：购买材料券 能否保证参加 满座 排队 退款。

### C05｜午餐与晚餐的确定性

问题：石间餐桌和豆灯家常，哪个更适合给两位不吃辣、想坐普通椅子的长辈安排一顿饭？请比较总价、能否直接改菜、入店台阶和错过接单时间的后果。

证据：石间 B016；豆灯 B060。

诊断子查询：石间套餐午市厨房酱汁入口；豆灯两人套餐无辣订位保留饭菜。

必须保留：石间午餐每人 72 元即两人 144 元、套餐十三点停止接单、单点到十四点、可减辣但预调酱汁不能全改、入口两级台阶无固定坡板；豆灯晚饭两人 118 元、十八点至二十点半、无辣组合需预约选择、入口十厘米台阶可请员工铺临时坡板、迟到保桌与保菜规则不同。两店都有普通椅，但石间预约不保证临窗。

比较结论：两店不是同一餐段，不能直接当作同一时刻可替换的选择。若确定吃晚饭、能提前确认无辣组合，可考虑豆灯；若吃午饭，应按石间能否做合适菜和跨阶能力确认。不能说石间每道菜都能去辣，也不能说豆灯临时改菜没有限制。

过滤观察点：诊断时保留问题原文，包括午晚餐适配性，避免为了提高重排分数删掉那些导致局部资料覆盖不足的条件。

### C06｜雨天室内的进入条件

问题：带不想爬楼的长辈遇雨，潮影放映室和砖缝展室，哪个更适合临时调整过去？请同时比较预约、台阶、座位、时段、费用和停留方式。

证据：潮影 B018；砖缝 B029。

诊断子查询：潮影旧胶片柜预约二十四级楼梯；砖缝门槛活动坡板靠背椅闭馆。

必须保留：潮影周末十五点分享、按预约名单、二层二十四级台阶、入场路段无遮檐、不卖电影票但不能据此断言所有其他服务也免费；砖缝周末十点至十七点、十六点半停止入内、不收费、一层四厘米门槛可借坡板、六张靠背椅、可短看可慢看约四十分钟。无证据证明砖缝必有空座，不保证临时坡板始终闲置。

比较结论：砖缝更符合临时调整与不爬楼的条件，但仍需现场确认坡板和座位。潮影题材独特不能消除预约、楼梯与抵达过程的淋雨限制。室内活动并不都代表入口和厕所条件相同。

过滤观察点：预约名单记录与老物件展室门口说明缺乏统一句式，是否仍能各自通过完整问题重排要实测。

## 五、汇总题：六个宽泛目标与可调整探索

不规定唯一标准路线，也不预写唯一查询序列。每题的“可能的探索转折”只是供评测人员核对的合理过程之一，不发给 Agent。可以从不同假设出发，只要后续变化有证据依据。不要要求公开详细内在推理；查询、返回事实与简短调整说明已经足够评估外显行为。

每题按 10 分评分：把宽泛需求转成可检验条件 2 分；发现并验证至少两类重要限制 3 分；新证据触发有理由的方向调整或替代评估 2 分；最终安排满足已知硬约束、标注未知并给出可行退路 3 分。若单轮已拿到全部事实，可给答案分，但不宣称已测得探索过程。

### S01｜安静的海边周末

问题：想和朋友在北海过个安静、有海边感觉、不太操心的周末，你会怎么安排？

初始含义不确定：“安静”可能是白天人少、没有扩音、夜里好睡；“海边感觉”可能是坐着看水，也可能要求住海边；“少操心”可能偏向稳定餐饮与交通。允许先询问偏好；无法问时声明采用哪一种解释。

可用证据：B005 风笛坪下午少人；B084 同地周六晚间舞台；B090 最后一班小车与叫车临停；B020 棉湾背风与晚间声音迹象；B108 具体排练与不同房型；B098 棉湾热食截止与距离；B040 芦湾晨间短停；B096 北入口午饭；B030 榆灯院内收声与步行条件；B069 声音偏好差异。

可能的探索转折：先把人少的海岸当候选 → 发现晚间扩音与返程限制 → 不再只搜清静海岸，转查停留时段或住宿房间声源 → 发现另一处背风也有排练与饭点限制 → 改为短停海边、住宿与饭点另行安排，或有条件地选择其中一处。

验收要求：不能把下午少人推成全天安静；不能把棉湾背风推成夜里好睡；不能在节目后依赖已经停班的小车；住宿安静若无数据须注明。最终不必去所有地点，至少解释为什么放弃或限制一个最初看似合适的选择。

### S02｜带爸妈舒服地待两天

问题：想带爸妈在北海舒服地待两天，看看海、吃顿像样的饭，别把他们弄累了，怎么安排比较妥？

不默认长辈有特定疾病，也不把所有人等同于轮椅使用者。可以询问连续步行、上下楼、午休和饭点偏好；未知时采用保守、明确的安排条件。

可用证据：B024 南窗房型与两条海边路；B027 青阶全部二层；B083 平路也可能临停挡坡；B054 夏木一层预订与两条线路；B087 不同座椅；B012 听雨茶间有座但后院如厕露天；B016、B060 餐饮及台阶；B029 一层展室；B104 照片背后的真实需求。

可能的探索转折：先查近海住处 → 发现最近的一家客房都在楼上 → 转查一层房与平路，而非继续排名海岸距离 → 查午后休息发现有座不等于全程不淋雨或方便如厕 → 转查设施与饭点，缩短原定连续步行。

验收要求：区分楼梯、路面、休息点和房内设施；不能把员工提箱当搀扶，也不能把房间一层推成浴室有扶手。不要为了显得丰富安排连续长步行。可推荐一个住宿候选加少量活动，不强求唯一酒店或路线。

### S03｜下雨也别扫兴

问题：周末可能下雨，和家人去北海，想保留一点海边度假的感觉，但不想湿着鞋来回折腾，有什么办法？

这里不要求证明实际天气。应根据给定不确定性判断哪些活动对雨、风、入口和座位有依赖，而不是只列一串室内景点。

可用证据：B006 骑楼不连续；B018 放映室室内但入口淋雨与楼梯；B029 砖缝的可进入条件；B059、B089 桥影是半开放且斜风停发；B076 银窗看海但有低消、窗位不保证与九十分钟上限；B094 阅间稳定室内但无海景；B111 拼贴随到随做但有容量与最后开包时间；B097 发现鞋湿后的目标变化；B116 备选需避免同样受天气限制。

可能的探索转折：先找遮雨散步 → 发现骑楼有断点、画桌不是真正室内 → 改查稳定座位和入口条件 → 发现海景窗位不能保证 → 把稳定休息与看海体验分开，或保留条件式海景选择，并安排能中断的移动段。

验收要求：不能称桥影完全室内，不能保证银窗有海景座，不能说砖缝随时都有椅子。室内替代可能失去海景，需诚实说明。遇到湿鞋不靠一句带伞敷衍，应调整活动和移动方式。

### S04｜带孩子少折腾

问题：想让孩子在北海玩得开心，大人也能轻松一点，周末两天怎么安排，不想一整天都在赶时间？

不预设孩子年龄、爱好与午睡规律。可询问；没有回复时，不把有年龄门槛的活动当成所有孩子都适用的默认安排。

可用证据：B003 冲脚与玩沙回店便利；B007 餐饮方便但到沙岸需过街；B092 玩水含义与清洗位置；B002 糖水排队与楼梯；B022 风筝六岁以上、定时与天气替代；B036 纸伞时段、厕所夹层、取作品期限；B111 随做拼贴容量；B100 推车照片的使用条件；B077 少景点不等于少步骤；B116 预约备选的冲突。

可能的探索转折：先找儿童活动 → 发现年龄、定点集合与额外取物 → 转查能随时结束的玩沙或随做项目 → 发现餐饮与午睡位置是新的瓶颈 → 在住宿与晚饭之间权衡，减少依赖节点而非继续增加活动。

验收要求：不要默认所有孩子能参加风筝；不要把玩沙等同下水；不要把住处冲脚当海岸洗澡；不能把有推车照片推成周末能在桌边睡觉。保留吃饭和休息的退路，明确哪些活动只是可选。

### S05｜预算有限但不委屈

问题：两个人想在北海住两晚，预算别太高，但也不想为了省一点钱一直将就，你会怎么选住处和安排吃玩？

预算上限和“将就”的含义未知。可询问总额及最在意的条件；未补充时只比较可确定的支出与服务差异，不虚构一个统一总预算。

可用证据：B033、B103 清潮固定费与自助条件；B030 榆灯含早与单程送行；B066 渔灯较贵但热食与夜间前台；B088 轻舟单人价格不能直接当两人价；B093 自炊不一定节省；B044、B060、B096 不同餐段与套餐；B040、B029 免费短停；B094 付费休息；B039 额外收费需要确认。

可能的探索转折：先按房费选最便宜 → 发现清洁费、早餐与不做饭条件 → 转查实际会用的服务和餐段 → 发现低价位置可能增加交通或夜间协助的不确定 → 给出固定支出明确、变量分开、有取舍的组合。

验收要求：清潮住宿固定支出 540 元，榆灯 640 元含两人早餐，不能编早餐单价计算最终总差。轻舟的单人两晚价格不适用于两人。免费地点与付费休息的功能不同，不以全面免费冒充不会将就。

### S06｜最后半天不被行李绑住

问题：周日在北海还有半天空闲，想轻松吃点东西、看看海，最后从旧街公共上车点离开，不想被行李和各种手续牵着走，怎么安排？

出发时刻、起始住处、行李尺寸与是否有待取物未知。可先问关键条件，或给出条件分支；不能自行假设已经参加全部手作活动。

可用证据：B050、B118 免费寄存造成折返与白栈十六点截止；B042 栖砂十七点与位置；B030 榆灯十九点寄存条件；B115 青瓦箱站至上车点四分钟、沙岸二十二分钟、柜型与凭条；B110 转角粥铺晚饭时段、六分钟到上车点、不提供离店寄存；B026 行李与离开方向；B036、B109、B086 手作取件仅在用户确有参加时作为分支；B063 休息与食物替代的区别。

可能的探索转折：先查免费寄存 → 发现要回海边住处取箱且可能超过截止 → 改查离开方向附近的柜站 → 查吃饭发现粥铺只供晚餐、不能继续寄存 → 根据实际离开时刻更换用餐选项，先处理行李再安排可结束的短停。

验收要求：不得在午后安排尚未营业的转角粥铺，也不能保证青瓦有空柜或放得下超大箱。对出发时间未知需给条件而非精确不可执行时间表。真正减少步骤的方案可舍弃海边一段，但应说明与用户看海需求的权衡。

## 六、比较过滤的对照方法

保持语料版本、模型、候选池、top-k、邻片扩展、查询改写、上下文增强和工具预算一致。至少测两组：基线为各子查询召回后用完整问题重排与过滤；对照为各子查询召回后按对应子查询重排过滤，再合并必要证据。这里描述的是实验方案，不代表项目已实现可一键切换的模式。

为了单独识别“重排用什么问题”的作用，先固定同一批候选，分别用完整问题和相应子查询打分。若两组连候选池都不同，结果同时受到召回变化影响，不能全部归因于重排。完整问题重排之前的每条正确候选都应有记录；只有最终候选列表而没有过滤前数据，不足以定位阈值造成的损失。

每题至少保存：完整问题、实际子查询、候选来源子查询、目标分片位置、召回名次、完整问题重排分数、子查询重排分数、当时阈值、是否被过滤、是否进入最终上下文、是否经邻片或父片恢复，以及答案是否缺一侧依据。不同重排模型的分数尺度不可直接横比。

阈值保持实际配置，先报告是否自然触发；可以另做阈值扫描，但扫描结果需注明。不得为了证明语料成功，临时抬阈值到几乎所有证据都被删，再声称重现了常见故障。若原问题和子查询分数都低，可能是文档不相关或模型无法识别，不是完整问题特有的损失。

如果关闭过滤后仍不能比较，检查事实是否齐全、模型是否读到两侧、共同标准是否成立。若关闭过滤就能恢复、并且低分证据是必要事实，可支持过滤导致失败的判断。一次回答不能证明因果，至少保留候选与分数证据；需要可靠比较时，对相同配置重复运行并分别报告波动。

## 七、汇总过程的观察边界

可观察的过程是：提出一个查询方向，获得事实，说明某个条件因此需要确认或某个候选需要降级，发出不同角度的查询，最终用证据支持取舍。换同义词可能只是重试，不一定体现方向调整；查询次数多也可能是低效或迷路。

有方向的变化例如从“人少的海岸”转向“晚间声源与返程”，从“便宜住处”转向“实际会用的早餐与夜间服务”，从“雨天景点”转向“稳定座位、入口与鞋湿后的退出路径”。每一次变化最好能对应刚发现的限制。若最初就提出了完整维度列表，并一次获得足够资料，也可能是高效表现，不应因没有绕路扣答案质量分，但不能据此认定已覆盖迭代探索能力。

可区分三种结果：没有找全关键事实；找全却未处理冲突；处理冲突并给出满足条件的取舍。最终方案要允许多个合理答案。证据覆盖不是把所有材料引用一遍，查到某项限制后有理由放弃该候选，可以算合理处理；故意忽略不利证据则不可以。

## 八、尚待实测的事项

本套语料没有真实性背书，目的在构造可核对的事实世界。《结构检查记录》只验证原指南的标题、链条连接和静态切分；《比较重排验证.json》另外记录本机缓存权重上的向量与重排实测。两者都不替代线上配置、BM25、上下文恢复或 Agent 运行的验证。

正式评测前先做六条起点问题的直接检索排查；对比较题检查两侧是否真的能分别召回且出现目标低分；对汇总题确认没有某个单片直接给出足够完整的路线。如果这些条件未成立，应修改语料或换题，保留失败记录，而不是只在评分时解释成成功。

实际工具预算若太小，四资料链和迭代探索可能因调用上限提前结束。应记录预算、超时与停止原因，区分检索能力不足和运行资源不足。单次工具可检索多个子问题时，调用次数与检索轮次也不是同一概念。
